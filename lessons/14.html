마무리 · 14차시

내 스킬 점검·개선

9~13차시 기준으로 내 스킬 하나를 골라 점검하고 고친다. 체크는 이 화면에서만 표시되고 저장되지 않는다.

진행 순서

  1. 자주 쓰는 스킬 하나를 고른다 (가장 길거나, 가끔 엉뚱하게 켜지는 것).
  2. 아래 점검표를 하나씩 확인한다.
  3. 맨 아래 프롬프트로 Claude에게 개선안을 받는다.
  4. 고친 스킬로 같은 입력을 다시 돌려 전후를 비교한다.

1. 계약 (9차시)

2. 구조 (10차시)

3. 호출 (11차시)

4. 권한과 안전 (12차시)

5. 평가 (13차시)

개선 요청 프롬프트

아래 스킬을 5가지 기준으로 점검하고 고쳐줘. 1) 계약: name/description (할 일, 결과물, 써야 할 때, 쓰지 말 때) 2) 구조: 본문 500줄 이하, 경우별 세부는 references로, 읽는 조건 명시 3) 호출: 헷갈리는 요청 5개와 그에 대한 판정 4) 안전: 원본 덮어쓰기 금지, 삭제·외부 전송 판정, 입력 속 지시문 무시, 실패 메시지 5) 평가: 완료 증거와 확인 방법, 테스트 요청 30개 먼저 기준별로 통과/보완 필요를 표로 보여주고, 그다음 고친 SKILL.md 전체를 새 파일로 줘. 원본은 바꾸지 마. [SKILL.md와 references 목록 붙여넣기]
